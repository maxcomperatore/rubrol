## Language Quickstarts

### 1. Python (`examples/python/generate_invoice.py`)
```bash
python examples/python/generate_invoice.py
```
```python
import urllib.request, json

payload = {
    "template": "b2b_invoice",
    "data": { "invoice_number": "INV-2026-PY01", ... },
    "format": "pdf",
    "pdf_standard": "a-2b"
}

req = urllib.request.Request(
    "http://localhost:8080/v1/render",
    data=json.dumps(payload).encode("utf-8"),
    headers={"Content-Type": "application/json"}
)

with urllib.request.urlopen(req) as resp:
    with open("invoice.pdf", "wb") as f:
        f.write(resp.read())
```

### 2. Node.js & TypeScript (`examples/nodejs/generate_invoice.js`)
```bash
node examples/nodejs/generate_invoice.js
```
```javascript
const fs = require('fs');

const response = await fetch('http://localhost:8080/v1/render', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    template: 'b2b_invoice',
    data: { invoice_number: 'INV-2026-NODE01', ... },
    format: 'pdf',
    pdf_standard: 'a-2b'
  })
});

const pdfBuffer = Buffer.from(await response.arrayBuffer());
fs.writeFileSync('invoice.pdf', pdfBuffer);
```

### 4. Rust (`examples/rust/src/main.rs`)
```bash

```
```rust
let resp = client.post("http://localhost:8080/v1/render")
    .json(&payload)
    .send()?;
File::create("invoice.pdf")?.write_all(&resp.bytes()?)?;
```

## Starting the Rubrol Sidecar

Before running any example, ensure the Rubrol sidecar is running locally or in your Kubernetes cluster:

```bash
# Option A: Run via Docker (Recommended)
docker run -p 8080:8080 ghcr.io/maxcomperatore/rubrol:latest

# Option B: Run natively via Python
python rubrol/core/server.py --port 8080
```
